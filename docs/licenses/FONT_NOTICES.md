# Generated bitmap-font notices

RustMix Wave embeds generated 1-bpp bitmap font strikes derived from:

- Inter (Medium and SemiBold): the user interface, `src/app/typography/assets.rs`
- Literata (Medium): book text, `src/app/reader_literata_assets.rs`
- Atkinson Hyperlegible Next (Medium): book text, `src/app/reader_atkinson_next_assets.rs`

Each strike covers printable ASCII, Latin-1 and the typographic characters
of Windows-1252. The strikes are generated by
`tools/fontgen/gen_bitmap_fonts.py` from the variable fonts published in
github.com/google/fonts (`Inter[opsz,wght].ttf`, `Literata[opsz,wght].ttf`,
`AtkinsonHyperlegibleNext[wght].ttf`). The repository contains only the
generated Rust arrays; the font files themselves are not distributed.

All three families are used under the SIL Open Font License 1.1, whose text
is retained in `docs/licenses/OFL-1.1.txt`.
